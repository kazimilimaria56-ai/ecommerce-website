# ecommerce-website not lest than 10 commits to each contributer

Ecommerce website project for software class.

## Project Overview
* **Company:** MSETI TECH
* **Department:** Software Development
* **Assignment Type:** Team Project (Frontend Development)
* **Tech Stack:** HTML5 & CSS3 (No Frameworks)

### Background / Scenario
You are a member of the Software Development Department at MSETI TECH COMPANY. The company has received a client request to design and build a responsive chair/furniture e-commerce landing page. As a team, you are tasked with developing this website using HTML and CSS, following the reference design provided.

The homepage is divided into 5 distinct sections:
1. Navigation Bar
2. Home Section (Hero)
3. Feature Section ("What make Our Chair special")
4. Testimonial Section ("We couldn't without these chair anymore")
5. Card Section ("Our bestselling chairs" - 3 product cards)

* **Languages Only:** Use only raw HTML5 and CSS3 (no frameworks unless permitted).
